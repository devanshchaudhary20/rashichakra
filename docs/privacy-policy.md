# Privacy Policy

**Last updated: May 11, 2026**

## About

Rashichakra is an automated Instagram account that publishes daily horoscope content. This privacy policy explains how the application operates with respect to data.

## Data We Collect

Rashichakra does not collect, store, or process any personal data from users or visitors.

## Instagram API Usage

Rashichakra uses the Instagram Graph API solely to publish daily horoscope images to the official [@gyaankhand](https://www.instagram.com/gyaankhand) Instagram account. The application:

- Does not collect data from Instagram users
- Does not access followers' profiles or data
- Does not store Instagram credentials beyond what is required for API authentication
- Uses access tokens only to publish content to the account owner's own profile

## Third-Party Services

Horoscope content is sourced from publicly available web pages. No user data is involved in this process.

## Contact

For any questions regarding this privacy policy, please contact us via Instagram at [@gyaankhand](https://www.instagram.com/gyaankhand).
